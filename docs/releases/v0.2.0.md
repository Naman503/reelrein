Download **ReelRein.apk** below. It updates 0.1.0 in place (same signing key).

### Added
- **Anonymous usage sharing, so I can see what helps.** On first open a card explains it, with a **Turn off** button. You can change it any time in **Settings → Privacy → Share anonymous usage**, and turning it off deletes what your install sent.
  - **Sent:** daily counts (Instagram opens, pause screens and whether you opened or closed Instagram, the limit you picked in ranges, reels, minutes on Reels and in Instagram, time's-up and reel-cap screens), which features and settings you use (names only, never values), setup steps, crashes (error type and where in ReelRein's code), a random install id, app version, Android version, phone model and language.
  - **Never sent:** anything on screen in Instagram (captions, comments, usernames, messages, which reels), your account, contacts, location or advertising id.
  - At most one report every 6 hours, to `api.np-dev.duckdns.org` only. CI now checks that the code talks to no other address.
- **Privacy section** in Settings, with "What's sent, and what never is".

### Changed
- ReelRein now asks for the internet permission, used only for the reports above. Before 0.2.0 it had none.
