## ReelRein 0.3.1: fewer glitches

- **No more double pause screen.** Opening Instagram shows the pause screen once, even with control centre, the notification shade or Instagram still loading behind it.
- **Locking the phone works properly.** Locking with Instagram open, the fingerprint screen and the charging screensaver no longer count as leaving. Unlock within the re-lock time and the reel carries on; after longer, you get the pause screen once.
- **No brain-full screen straight after the pause screen.** Continuing from the pause screen counts as having seen the reel cap.
- **2x locks faster.** Instagram's "Locked at 2x" message is now read correctly, so there's no second press on each reel.
- **Auto scroll switches on reliably.** It waits for Instagram's menu to finish sliding in, and retries once.
- **Bank-safe mode reacts faster.** It checks every 0.3 s and covers Instagram as soon as it wakes.
